# AI-Based Smart Attendance System

An AI-powered attendance management system that uses facial recognition
to identify registered students and automatically record their attendance.

## Features

- Admin login and authentication
- Student registration
- Face detection and recognition
- Automatic attendance marking
- Unknown face detection
- Attendance records
- Present and absent statistics
- Admin dashboard

## Technologies Used

- Python
- Flask
- OpenCV
- LBPH Face Recognizer
- SQLite
- HTML
- CSS
- JavaScript
